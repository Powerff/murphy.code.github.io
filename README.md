# murphy.code

Personal site for **murphy** (GitHub account: [Powerff](https://github.com/Powerff)).

**Live:** https://powerff.github.io/

## Why not murphy.github.io / murphyCode.github.io?

GitHub Pages user URLs are `https://<username>.github.io/` (username matching is **case-insensitive**).

Already taken by other accounts:

- [`murphy`](https://github.com/murphy) → cannot use `murphy.github.io`
- [`murphycode`](https://github.com/murphycode) → cannot use `murphyCode.github.io` / `murphycode.github.io`

So this site stays under `Powerff` → `https://powerff.github.io/`.

Alternatives if a shorter/custom brand URL is required later:

1. Rename the GitHub account to an **available** handle (examples that were free when last checked: `murphycloud`, `murphy_code`, `murphyCodeLab`), then use that `.github.io`
2. Buy a custom domain (e.g. `murphy.code`) and bind it in Pages settings
